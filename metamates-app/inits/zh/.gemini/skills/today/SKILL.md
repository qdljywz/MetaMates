# 📅 今日计划 (Today)

请执行以下任务：

1. **读取今日日记**：查找 `01_日记与计划/` 目录下今天的日记文件（格式：YYYY-MM-DD.md）
2. **读取日历和任务**：查找相关任务列表和日历安排
3. **读取 Master_Control**：查看 `05_模板与配置/Master_Control.md` 中的本周目标和优先级
4. **生成今日计划**：基于以上信息，生成按优先级排序的今日行动方案

## 输出格式
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📅 今日计划：[日期]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 核心目标
- [目标1]
- [目标2]

⏰ 时间安排
- 09:00–12:00 — 任务说明（可含优先级备注）
- 14:00 — 硬节点任务

📋 待办事项
- [ ] 任务1
- [ ] 任务2

💡 今日提醒
- 提醒事项
```

---

## 写回与状态栏日程（MetaMates 强制）

- **必须**用 Write 写回 `01_日记与计划/YYYY-MM-DD PLAN.md`（空格 + `PLAN.md`，不是下划线）
- **时间行必须**用下列可解析格式之一（状态栏「今日 N 项日程」只认这些）：
  - `- 09:00–12:00 — 标题` / `- 14:00 — 标题`（推荐，与现有 MyM2 一致）
  - 或 `- [ ] **09:00 - 11:00**：标题`（模板 checkbox 格式）
- **禁止**只输出 `- [时间] - [任务]` 占位符；禁止只聊天不落盘
- 写后 **Read 验证**（Act & Verify）
