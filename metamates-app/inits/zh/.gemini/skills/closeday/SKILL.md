# 🌙 每日复盘 (Closeday)

请执行以下任务：

1. **回顾今日工作**：扫描今日完成的任务和进展；读取今日日记 `01_日记与计划/YYYY-MM-DD.md`
2. **番茄钟自动同步正文**（必执行·闭环规则）
   - 读取日记 `## 番茄钟` / `## Pomodoro` 区；MetaMates 写入格式：`- [x] 10:00–10:25 (25m) 事项说明`
   - 对每条已勾选 `[x]`：在「✅ 今日完成」追加 `✅ **[内容]**（🍅 [时段] · [时长]）`（无该区则创建）；去重；「仅参与者」不强制产出
   - 移除「🟡 待执行」中已完成项；更新「最后更新」若存在；**保留** `## 番茄钟` 底稿不删
3. **总结进展**：提炼核心成果和里程碑（含已同步的番茄钟产出）
4. **捕获新想法**：记录今日产生的新想法或灵感
5. **列出结转任务**：标记未完成事项，准备明日继续
6. **更新 Master_Control**：同步今日复盘结果
